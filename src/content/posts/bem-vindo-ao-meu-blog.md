# Bem-vindo ao Blog!

Este é um post de exemplo criado com o **Decap CMS** (antigo Netlify CMS). A partir de agora, você pode escrever seus artigos diretamente pela interface web, sem precisar editar código!

## Como escrever novos posts

1. **Acesse o CMS**: Vá para `https://seu-site.com/admin`
2. **Faça login**: Use sua conta do GitHub
3. **Crie um novo post**: Clique em "Novo Post"
4. **Preencha os campos**: Título, conteúdo, categoria, tags, etc.
5. **Salve como rascunho**: Seu post ficará em "Draft" no GitHub
6. **Revise e publique**: Quando estiver pronto, mova para "Ready" e publique
