# Imagens Mock

Esta pasta contém imagens de exemplo para demonstrar o sistema de upload.

Em produção, as imagens seriam salvas em um servidor de arquivos ou CDN.

## Estrutura:

- `/public/images/` - Imagens gerais
- `/public/images/uploads/` - Imagens enviadas pelos usuários (simulado)

## Formatos suportados:

- PNG
- JPG/JPEG
- WebP
- AVIF
